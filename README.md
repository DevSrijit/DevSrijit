### Srijit Ghosh

Product engineer in Kolkata. I build whole products alone, from the design system to the servers.

I am the cofounder and CTO of [CommSync](https://commsync.ai), an AI inbox for email and SMS. I designed and built all of it: the Next.js web app, the [iPhone app](https://apps.apple.com/app/id6810334130), the Bun backend and the infrastructure. I also build AI agents and the harnesses they run in: tool use, memory, browser control and MCP.

#### Things I made

| | |
| --- | --- |
| [**untell**](https://github.com/DevSrijit/untell) | Gives coding agents eyes for video. Records each film, runs 122 checks on every frame and the sound, and names each fix. Open source, on npm. |
| [**Million**](https://github.com/DevSrijit/million) | A spreadsheet engine for the browser, written from scratch. A million rows, every formula live, and a small edit in microseconds. |
| [**Blackbox**](https://github.com/DevSrijit/blackbox) | A flight recorder for AI agents. Replay a run, see what every LLM call cost, and price it on any OpenRouter model. |
| [**DualSense Studio**](https://github.com/DevSrijit/dualsense-studio) | Control the PS5 controller's lightbar, triggers and haptics from the browser over WebHID. |
| [**Vitals**](https://github.com/DevSrijit/vitals) | Whoop-style recovery and strain scores from a cheap watch, computed on your own machine, with an MCP server. |
| [**WLED Ambient Lighting**](https://github.com/DevSrijit/WLED-Ambient-Lighting) | Mirrors the colours on your screen to an LED matrix in real time. |
